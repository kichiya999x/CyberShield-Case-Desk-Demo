# CyberShield: Case Desk

[Play CyberShield: Case Desk](https://kichiya999x.github.io/CyberShield-Case-Desk-Demo/)

An interactive cybersecurity investigation simulator for the CyberShield academic exhibit. Version V2.2 uses fictional training records to introduce three security principles:

| Case | Investigation | Principle |
| --- | --- | --- |
| 01 — The Double Assignment | Compare an existing issuance with a conflicting attempt. | Data integrity |
| 02 — The Missing Logbook Clue | Follow a recorded custody trail. | Traceability and accountability |
| 03 — The Restricted Record | Compare reference and maintenance access. | Least privilege / role-based access control |

Choose a case, read the briefing, and select **Begin Investigation**. Examine records, follow the guide, and make your decision. Case 02 is recommended first. **Free Exploration** and the optional **Security Analyst Challenge** are also available.

Use **New visitor → Reset Mission** to clear the session, or **NEW VISITOR — RESET MISSION** after completion. Refreshing also starts fresh.

This is a fictional educational reconstruction, with no connection to an operational firearm-record system. It does not issue, approve, return, maintain or transfer real records or grant account permissions. The application adds no login, analytics, personal-data forms or persistent visitor storage. Session progress exists only in the running browser page.
